# User Guide for Beginner

## شروع

### پروژه جدید
`پروژه جدید` → نام پروژه → مشتری → ساخت

### فایل قدیمی
`ورود Excel` → فایل را انتخاب کن → تمام Sheetها داخل Workbook ظاهر می‌شوند.

## کار با Sheet

روی Sheet موردنظر بزن.

- روی سلول کلیک کن و مقدار را تغییر بده.
- با `=` فرمول وارد کن.
- +R یعنی افزودن ردیف.
- +C یعنی افزودن ستون.
- −R و −C برای حذف هستند.

## نقشه‌کشی

### ابزارها

`V` انتخاب

`L` خط

`P` چندخطی

`R` مستطیل

`C` دایره

`D` اندازه

`T` متن

`H` جابجایی صفحه

### اندازه واقعی

تمام هندسه در mm ذخیره می‌شود. واحد نمایش را می‌توان به mm، cm، m، in یا ft تغییر داد.

### نمایش سایز

یک شیء را انتخاب کن و گزینه «نمایش اندازه شیء انتخابی» را روشن کن. اندازه واقعی در اطراف شیء نمایش داده می‌شود.

### شیت زنده

هر قطعه‌ای که با Rectangle/Line/Polyline ساخته شود در `نقشه-قطعات` ثبت می‌شود.

## نجات اطلاعات

# UX Revision 2.3

The dashboard now uses compact typography, action-first cards, recent-project shortcuts, a clear 4-step path, and a smaller visual hierarchy so the interface reads better on phones and desktops.

Responsive breakpoints:
- Desktop: multi-column workspace
- Tablet: stacked dashboard panels
- Phone: two-column quick actions, compact cards, touch-friendly controls

Typography is intentionally smaller than v2 because the previous build was visually oversized.

# Changelog

## 2.0.0

- بازطراحی UI برای کاربر مبتدی
- ورک‌بوک چندشیتی قابل ویرایش داخل سایت
- Drawing Studio دوبعدی جدید با مختصات واقعی میلی‌متری
- ابزار خط، چندخطی، مستطیل، دایره، اندازه‌گذاری، متن، Pan و Zoom
- Grid و Snap
- نمایش اندازه شیء انتخاب‌شده
- Property Editor برای مختصات و ابعاد
- شیت زنده `نقشه-قطعات`
- Auto Save و Snapshot
- KWM portable project file
- PDF پروژه و PDF نقشه
- Excel/CSV export
- Cloudflare Worker v2 با `/health`, `/test-telegram`, `/backup`
- ارسال جداگانه KWM/XLSX/PDF به Telegram
- CORS و خطاهای قابل‌تشخیص
- تنظیمات امنیتی برای Secretها

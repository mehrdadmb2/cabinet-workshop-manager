## Drawing

در فایل‌های مرجع، Objectهای Shape و Connector هم دیده می‌شوند. این موضوع دلیل اصلی ایجاد Drawing Studio مستقل است.

## رفتار Import

Import باید:

- نام همه Sheetها را حفظ کند.
- ابعاد اصلی used range را حفظ کند.
- مقدار و Formula هر سلول را تا حد ممکن حفظ کند.
- Mergeها را منتقل کند.
- Width ستون‌ها را تا حد ممکن حفظ کند.
- Sheet جدید `نقشه-قطعات` را برای طراحی وب بسازد/به‌روزرسانی کند.
